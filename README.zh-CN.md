# 求职申请材料 Skill

[English](README.md)

这个 Codex Skill 根据岗位描述和个人档案生成有针对性的 LaTeX 简历与动机信。需要通过邮箱申请时，它也会起草简短正式的邮件。

## 需要提供什么

- **岗位描述。** 提供招聘网页链接、岗位正文或附件。
- **个人档案。** 将 [英文档案模板](profile.template.md) 复制为私下保存的 `profile.md`，填写适用的部分，再上传文件或告诉 Codex 本地路径。也可以附上相关项目报告、作品集等资料。
- **自定义 LaTeX 模板（可选）。** 可替换简历或动机信模板，或两份都换。请一并提供模板引用的章节文件、样式、图片或字体。未指定的部分使用内置模板。

## 如何使用

1. 在 Codex 调用 `$prepare-job-application`，或说「帮我生成岗位申请材料」，并提供岗位描述、个人档案及自定义模板的位置。
2. 核对岗位分析和材料草稿。材料使用招聘方指定的申请语言。招聘方没有指定时，使用岗位描述的主要语言。申请语言与对话语言不同时，审核稿会同时提供原文和译文。
3. 确认草稿后编译。优先使用 Codex 内置 LaTeX 编译器，需要导出 PDF 时也可使用本机已有的兼容编译器。如果当前环境无法编译或导出，仍会交付 `.tex` 源文件。

请在公开仓库之外保存填写后的个人档案和申请材料。内置模板的作者、来源和许可证见[第三方许可说明](THIRD_PARTY_NOTICES.md)。
