# 求职申请材料 Skill

[English](README.md)

这个 Codex Skill 根据岗位描述和个人档案生成有针对性的 LaTeX 简历与动机信。需要通过邮箱申请时，它也会起草简短正式的邮件。

## 需要提供什么

- **岗位描述。** 提供招聘网页链接、岗位正文或附件。也可以提供已有的岗位分析，直接进入材料起草环节。
- **个人档案。** 将 [英文档案模板](profile.template.md) 复制为私下保存的 `profile.md`，填写适用的部分，再上传文件或告诉 Codex 本地路径。如需补充经历，也可以提供相关报告、作品集、原项目文件或工作资料。
- **自定义 LaTeX 模板（可选）。** 可替换简历或动机信模板，或两份都换。请一并提供模板引用的章节文件、样式、图片或字体。未指定的部分使用内置模板。

- **简历照片（可选）。** 提供照片并确认希望用于申请。

文件可以直接拖到对话框，也可以提供本地路径。通过路径提供时，建议保留原件或备份。Skill 会在私有工作副本里更新个人档案，并从模板副本生成每次申请的 LaTeX 文件。

## 如何使用

1. 在 Codex 调用 `$prepare-job-application`，或说「帮我生成岗位申请材料」，并提供岗位描述或已有分析。首次生成简历前，Codex 会检查个人档案及相关证明材料，按需询问是否提供自定义模板和照片。后续申请会复用私有个人档案副本。
2. 选择申请文件夹，用于保存岗位原文或译文、分析报告和申请材料。Codex 会建议按公司和岗位命名的文件夹。也可以选择逐个下载文件。
3. 核对 Markdown 岗位分析、简历草稿和两版动机信。可选一版或合并两版。申请语言与对话语言不同时，审阅稿会同时提供原文和译文。
4. 确认简历和选定的动机信后编译。优先使用本机已安装且兼容的 LaTeX 编译器。如果本机没有兼容的编译器，则使用 Codex 内置 LaTeX 编译器。如果当前环境无法编译或导出，仍会交付 `.tex` 源文件。

请在公开仓库之外保存填写后的个人档案和申请材料。内置模板的作者、来源和许可证见[第三方许可说明](THIRD_PARTY_NOTICES.md)。
