# Review and compilation

Show the originals for review, with a translation into the user's conversation language when it differs from the application language. Keep the meaning and strength of claims aligned across versions and apply the user's edits to both. Compile preview PDFs as needed before approval to verify and adjust layout, and identify any shown preview as a draft. Wait for explicit approval of the requested final documents before producing the final approved PDFs. Layout-only adjustments do not require repeated content approval; substantive wording changes do.

Before showing generated resume or cover-letter source for review, render lowercase ß in visible LaTeX text with `\ss{}`, including in names and addresses. For example, write `Stra\ss{}e` for Straße. Preserve original spelling in profiles, plain text, file paths, and URL targets. Handle other scripts and diacritics according to the selected template and compiler, and check the rendered characters when compiling.

Use a compatible locally installed LaTeX compiler when available. If none is available, use Codex's built-in LaTeX compiler. Get the user's consent before installing software or sending documents to an external compiler.

Check that the requested PDFs open and render correctly and that any stated upload limits are met. If compilation reveals a need for substantive wording changes, show the revisions for approval before producing the final approved PDF. Deliver the requested LaTeX sources with their required local assets and the requested PDFs. If compilation or export is unavailable, deliver the sources and explain the blocker.
